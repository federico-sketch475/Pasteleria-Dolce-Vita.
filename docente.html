Memoria técnica

Documentación del desarrollo del sitio web de la pastelería artesanal Dolce Vita.

1. Etiquetas semánticas HTML5

Se utilizaron etiquetas semánticas de HTML5 para organizar correctamente la estructura y mejorar la comprensión del contenido.

  • <header>: contiene el encabezado y la navegación.
  • <nav>: contiene el menú principal.
  • <main>: contiene el contenido principal.
  • <section>: divide el contenido en diferentes secciones.
  • <article>: se utiliza para productos y contenidos independientes.
  • <footer>: contiene la información final del sitio.

2. Stack tecnológico y estilos

  • HTML5 para la estructura del sitio.
  • CSS3 para el diseño y presentación visual.
  • JavaScript para la interactividad.
  • CSS Grid para organizar tarjetas y contenidos.
  • Flexbox para la navegación y diferentes elementos.
  • Media Queries para adaptar el sitio a diferentes pantallas.

3. Diseño Responsive

El sitio fue desarrollado para adaptarse a computadoras, tablets y teléfonos celulares. Se utilizaron Media Queries para modificar la distribución de las columnas, tamaños y navegación cuando disminuye el ancho de la pantalla.

4. Justificación de la arquitectura

Se eligió inicialmente una arquitectura One-Page porque permite presentar la información de la pastelería de forma organizada dentro de una única página.

La navegación utiliza anclajes internos para desplazarse rápidamente entre las diferentes secciones.

Además, mediante JavaScript se identifica la sección visible durante el desplazamiento y se activa el enlace correspondiente en el menú.

5. Internacionalización

El sitio presenta información en español e italiano para reforzar la identidad de la pastelería y su inspiración italiana.

JavaScript permite cambiar dinámicamente entre ambos idiomas mediante un botón ubicado en el menú principal.

6. Recursos externos y accesibilidad

Se utilizaron imágenes provenientes de repositorios externos. Las imágenes cuentan con atributos alt descriptivos que explican su contenido para mejorar la accesibilidad y aportar información a los motores de búsqueda.

7. Interactividad y experiencia de usuario

Se incorporaron botones de consulta funcionales en cada producto. Al seleccionar una torta, el usuario es dirigido al formulario de contacto y el mensaje se completa automáticamente con el producto seleccionado.

También se incorporaron efectos hover en productos y botones, animaciones visuales y un indicador de sección activa en el menú.

8. Conclusión

El proyecto busca combinar una identidad visual inspirada en la pastelería italiana con una estructura web moderna, accesible y adaptable a diferentes dispositivos. Las mejoras implementadas buscan facilitar la navegación y generar una experiencia más clara e intuitiva para el usuario.
